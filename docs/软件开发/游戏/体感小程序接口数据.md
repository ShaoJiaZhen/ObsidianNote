# 训练接口 JSON 数据格式说明

## 1. 接口说明

当前接口用于生成训练入口，支持两种模式：

| 模式 | mode | 说明 |
|---|---|---|
| 单个动作模式 | `single` | 一次训练一个动作 |
| 动作编排模式 | `workout` | 一次训练多个动作，按顺序执行 |

接口地址：

```text
POST http://localhost:3000/api/training-actions
```

---

## 2. 单个动作模式

### 请求 JSON

```json
{
  "mode": "single",
  "exerciseId": "side-raise",
  "targetReps": 2,
  "autoStart": true,
  "followAlong": false
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | string | 是 | 固定为 `single` |
| `exerciseId` | string | 是 | 动作 ID |
| `targetReps` | number | 否 | 本次训练目标次数 |
| `autoStart` | boolean | 否 | 是否进入页面后自动开始 |
| `followAlong` | boolean | 否 | 是否开启跟练模式 |

### 返回 JSON

```json
{
  "item": {
    "mode": "single",
    "exerciseId": "side-raise",
    "exerciseName": "侧平举",
    "category": "arm",
    "followAlong": false,
    "autoStart": true,
    "targetReps": 2,
    "trainingUrl": "/sport/train?exercise=side-raise&autoStart=1&targetReps=2",
    "absoluteTrainingUrl": "http://localhost:3000/sport/train?exercise=side-raise&autoStart=1&targetReps=2"
  },
  "serverTime": 1777000435490
}
```

---

## 3. 动作编排模式

### 请求 JSON

```json
{
  "mode": "workout",
  "items": [
    {
      "exerciseId": "side-raise",
      "targetReps": 2
    },
    {
      "exerciseId": "squat",
      "targetReps": 3
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mode` | string | 是 | 固定为 `workout` |
| `items` | array | 是 | 动作编排列表 |
| `items[].exerciseId` | string | 是 | 动作 ID |
| `items[].targetReps` | number | 是 | 当前动作目标次数 |

### 返回 JSON

```json
{
  "item": {
    "mode": "workout",
    "items": [
      {
        "exerciseId": "side-raise",
        "exerciseName": "侧平举",
        "category": "arm",
        "targetReps": 2
      },
      {
        "exerciseId": "squat",
        "exerciseName": "深蹲",
        "category": "leg",
        "targetReps": 3
      }
    ],
    "totalExercises": 2,
    "totalTargetReps": 5,
    "autoStart": true,
    "trainingUrl": "/sport/workout?items=side-raise%3A2%2Csquat%3A3",
    "absoluteTrainingUrl": "http://localhost:3000/sport/workout?items=side-raise%3A2%2Csquat%3A3"
  },
  "serverTime": 1777000435490
}
```

---

## 4. 可用动作 ID

| exerciseId | 动作名称 | 分类 |
|---|---|---|
| `side-raise` | 侧平举 | arm |
| `overhead-press` | 过头上举 | arm |
| `bicep-curl` | 二头弯举 | arm |
| `squat` | 深蹲 | leg |
| `leg-abduction` | 直腿侧抬 | leg |
| `leg-raise-front` | 直腿前抬 | leg |
| `head-turn-left` | 转头向左 | head |
| `head-turn-right` | 转头向右 | head |
| `head-up` | 抬头 | head |
| `head-down` | 低头 | head |
| `head-rotate-left` | 头部左绕环 | head |
| `head-rotate-right` | 头部右绕环 | head |

## 5. 训练结果上传接口

训练完成后，数据上传到：

```text
POST http://127.0.0.1:3301/api/training-sessions
```

### 请求 JSON

```json
{
  "id": "sess-test-20260424-001",
  "exerciseId": "side-raise",
  "exerciseName": "侧平举",
  "reps": 2,
  "durationSec": 12,
  "startedAt": 1777000023995,
  "endedAt": 1777000035995,
  "targetReps": 2,
  "goalMet": true,
  "kcal": 1
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 训练记录 ID |
| `exerciseId` | string | 动作 ID |
| `exerciseName` | string | 动作名称 |
| `reps` | number | 实际完成次数 |
| `durationSec` | number | 训练时长，单位秒 |
| `startedAt` | number | 开始时间戳 |
| `endedAt` | number | 结束时间戳 |
| `targetReps` | number | 目标次数 |
| `goalMet` | boolean | 是否达标 |
| `kcal` | number | 估算消耗热量 |
