# 听力康复训练系统前端所需接口

## 1. 用户账号

- 用户注册：`POST /api/v1/auth/register`
- 用户登录：`POST /api/v1/auth/login`
- 用户退出：`POST /api/v1/auth/logout`
- 获取当前用户：`GET /api/v1/me`
- 修改用户资料：`PATCH /api/v1/me`

## 2. 用户设置

- 获取用户设置：`GET /api/v1/me/settings`
- 保存用户设置：`PATCH /api/v1/me/settings`
- 获取通知设置：`GET /api/v1/me/notification-settings`
- 保存通知设置：`PATCH /api/v1/me/notification-settings`

## 3. 训练模块

- 获取首页训练模块：`GET /api/v1/training/modules?category=top`
- 获取基础听觉训练模块：`GET /api/v1/training/modules?category=basic-auditory`
- 获取综合认知训练模块：`GET /api/v1/training/modules?category=cognitive`
- 获取训练模块详情：`GET /api/v1/training/modules/{moduleId}`

## 4. 训练答题

- 开始训练：`POST /api/v1/training/sessions`
- 获取训练会话：`GET /api/v1/training/sessions/{sessionId}`
- 获取下一道题：`GET /api/v1/training/sessions/{sessionId}/question`
- 提交答案：`POST /api/v1/training/sessions/{sessionId}/answers`
- 完成训练：`POST /api/v1/training/sessions/{sessionId}/complete`
- 放弃训练：`POST /api/v1/training/sessions/{sessionId}/abandon`

## 5. 训练记录

- 获取历史记录：`GET /api/v1/training/results`
- 获取记录详情：`GET /api/v1/training/results/{resultId}`
- 删除单条记录：`DELETE /api/v1/training/results/{resultId}`
- 清空全部记录：`DELETE /api/v1/training/results`
- 获取统计汇总：`GET /api/v1/training/stats/summary`
- 获取训练趋势：`GET /api/v1/training/stats/trends`
- 获取能力维度：`GET /api/v1/training/stats/dimensions`

## 6. 音乐放松

- 获取放松项目列表：`GET /api/v1/relax/programs`
- 获取放松项目详情：`GET /api/v1/relax/programs/{programId}`
- 开始音乐放松：`POST /api/v1/relax/sessions`
- 完成音乐放松：`POST /api/v1/relax/sessions/{sessionId}/complete`
- 获取音乐放松记录：`GET /api/v1/relax/sessions`

## 7. 软件内容

- 获取软件配置：`GET /api/v1/app/config`
- 获取隐私政策：`GET /api/v1/content/privacy-policy`
- 获取关于软件：`GET /api/v1/content/about`
