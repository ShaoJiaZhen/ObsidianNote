## 1. 商业模式画布总览

商业模式画布可以理解为：把自己当成一家公司来经营，用一张图看清楚“为谁创造价值、如何创造价值、如何触达客户、如何获得回报、需要投入什么成本”。

### 九个模块

| 编号 | 模块 | 英文 | 核心问题 | 示例 |
|---|---|---|---|---|
| 01 | 客户细分 | Customer Segments | 为谁服务？ | 大众市场、细分市场、利基市场 |
| 02 | 价值主张 | Value Proposition | 解决什么问题？提供什么价值？ | 产品价值、服务价值、效率提升、情绪价值 |
| 03 | 渠道通路 | Channels | 如何触达、传递和服务客户？ | 线上平台、社群、内容渠道、线下渠道 |
| 04 | 客户关系 | Customer Relations | 如何获取、维系和增长客户？ | 获取、维系、增长 |
| 05 | 收入来源 | Revenue Streams | 如何获得收入？ | 销售、订阅、授权、广告 |
| 06 | 核心资源 | Key Resources | 依靠什么资源创造价值？ | 实物、知识、人力、财务 |
| 07 | 关键业务 | Key Activities | 关键要做什么？ | 生产制造、平台运营、内容输出、服务交付 |
| 08 | 重要伙伴 | Key Partners | 谁能帮助我？ | 供应商、战略联盟、资源共享方 |
| 09 | 成本结构 | Cost Structure | 需要付出什么？ | 固定成本、可变成本、规模经济 |

### 使用价值

- **战略对齐**：让团队在同一张图上对齐商业逻辑。
- **快速诊断**：识别商业模式中的薄弱环节与机会。
- **创新设计**：系统性探索新商业模式，而不是局部优化。
- **竞品分析**：用同一框架拆解竞争对手的商业逻辑。

## 2. 九问看透个人商业模式

个人商业模式画布的重点，是把“自己”当成经营主体，回答自己拥有的资源、提供的价值、服务的人群、传播渠道、合作伙伴、收入与成本。

| 模块 | 自我提问 | 引导追问 |
|---|---|---|
| 01 核心资源 | 我是谁？我拥有什么？ | 你的性格、兴趣、知识、技能、经验、人脉，以及其他有形、无形的资源资产，真的盘点过吗？ |
| 02 关键业务 | 我要做什么？ | 你每天在做的事情、承担的任务、正在推进的工作，哪些是真正重要的？哪些只是在消耗你？ |
| 03 客户群体 | 我能帮助谁？ | 我做的事情会对哪些人有帮助？哪些人愿意为此买单？他们在哪里？ |
| 04 价值主张 | 我怎样帮助他人？ | 我做的事情，能给他人带来什么帮助、好处、价值？如果你说不清楚，别人也感受不到。 |
| 05 渠道通路 | 我通过什么提供价值？ | 如何让客户知道你的存在？如何营销自己？如何将自己的服务产品化、常态化？ |
| 06 客户关系 | 怎样与对方打交道？ | 我与客户建立什么样的关系？需要维系哪些关系？如何维护？关系是资产，你在经营吗？ |
| 07 重要伙伴 | 谁可以帮助我？ | 哪些人是你的合作伙伴？可以和你交换资源、互相支持、共同进步吗？你有在主动寻找吗？ |
| 08 收入来源 | 我能获得什么？ | 硬性收入：工资、奖金、项目收益。软性收入：成就感、满足感、自我价值感。两者你都在意吗？ |
| 09 成本结构 | 我要付出什么？ | 硬性成本：时间、精力、金钱。软性成本：压力、家庭、机会成本。你算过这笔账吗？ |

## 3. 知识博主商业模式画布

### 画布内容

| 模块 | 内容 |
|---|---|
| 01 客户细分 | 想提升学习力的人；想提升记忆力的人；思维图影响力人群；出版社 / 作者；自媒体运营人员 |
| 02 价值主张 | 实用有价值的干货；用思维导图学知识；提升高效学习力；用脑图卡片学习；提升逻辑思维能力；帮助整理收获传播 |
| 03 渠道通路 | 平台的作品；他人的介绍；朋友圈 / 社群分享；其他推广 |
| 04 客户关系 | 粉丝与学员；平台持续输出；社群 / 公众号；微信朋友圈 |
| 05 收入来源 | 显性收入：课程收入、推广佣金、广告合作；隐形收入：知识增长、能力增长、影响力增长 |
| 06 核心资源 | 超强的学习力；设计产品的能力；超强的输出力；可视化表达能力 |
| 07 关键业务 | 输出好内容；开设好课程；运营好平台；感恩老师团队 |
| 08 重要伙伴 | 关注我的粉丝；信任我的学员；团队合作伙伴；给我资源的平台；业内同僚；我的老师 |
| 09 成本结构 | 隐性成本：时间、精力、心力、其他机会；显性成本：金钱、办公场地 |

### 核心洞察

- **知识变现**：以思维导图为核心工具，将学习力转化为产品与收入。
- **双轨收益**：显性收入，如课程和广告；隐形收入，如影响力增长，两者并行增长。
- **内容飞轮**：持续输出优质内容，驱动粉丝增长与信任积累。
- **能力护城河**：学习力、输出力、可视化能力，构建难以复制的个人壁垒。

## 4. 职场人商业模式画布

### 画布内容

| 模块 | 内容 |
|---|---|
| 01 客户细分 | 公司领导；同事下属；公司客户；同行大神；粉丝朋友 |
| 02 价值主张 | 为上级分忧；为公司创收；助属下提升；帮同事成长；为粉丝服务 |
| 03 渠道通路 | 公司会议；行业交流；同行学习；私域媒体 |
| 04 客户关系 | 合作者；分享者；意见领袖 |
| 05 收入来源 | 回报：工资待遇、工作经验、满足成就 |
| 06 核心资源 | 努力 / 情商；技能 / 经验；团队 / 人脉；行业内幕 |
| 07 关键业务 | 本职工作；技能提升；行业洞察；做副业 |
| 08 重要合作 | 上级领导；同事下属；行业大神；同学同行；自媒体 |
| 09 成本结构 | 付出：时间精力、身体健康、人脉资源 |

### 核心洞察

- **职场即市场**：把自己当产品经营，用商业思维管理职业生涯。
- **价值可视化**：明确“我能提供什么”，是职场竞争力的核心命题。
- **隐性回报**：经验与成就感是真实资产，不亚于薪资的长期复利。
- **人脉即渠道**：上级、同行、粉丝构成传播网络，影响力是最低成本的渠道。
